# Assets de la landing

Para publicar la landing en GitHub Pages:

- Configurar Pages con branch `main` y carpeta `/docs`.
- Reemplazar `propuesta-meta-ads.pdf` por el PDF final de propuesta.
- Si hay foto de perfil, guardarla en esta carpeta y reemplazar el bloque `.profile-photo` del `index.html` por una imagen.
- Completar `whatsappUrl` en `main.js` con el link real, por ejemplo `https://wa.me/549...`.

No subir capturas internas, datos reales de clientes, IDs de cuentas publicitarias ni información sensible de la plataforma.
